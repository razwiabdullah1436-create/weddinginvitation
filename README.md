# Wedding Invitation — Trilingual

A mobile-friendly interactive wedding invitation in **English, Hindi and Urdu**.

## Features
- Welcome screen with language selection
- English / हिन्दी / اردو invitation flows
- One-screen-at-a-time swipe navigation
- Swipe/finger tutorial
- Embedded Urdu fonts
- Mr Faizie branding and contact
- Google Maps venue button
- GitHub Pages ready

## Deploy on GitHub Pages
1. Create a new GitHub repository.
2. Upload **everything inside this folder** to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. GitHub will provide the live website URL.

Keep `index.html` and the `assets` folder together.
